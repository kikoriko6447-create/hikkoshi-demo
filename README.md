# 引っ越し段取り表（デモ）

引っ越し日を1つ入れると、前後の段取りが自動で並ぶスケジュール表です。
バーをドラッグすると、後ろの予定が全部まとめてついてきます。

- HTMLファイル1枚だけで動きます。ビルド不要・サーバー不要
- Vue 3 と Tailwind を CDN から読み込んでいるだけです
- データは端末の中だけで完結します。どこにも送信していません

## URLで初期状態を指定できます

| クエリ | 意味 |
|---|---|
| `?move=2026-10-23` | 引っ越し日を指定 |
| `?home=rent` / `?home=own` | 今の住まい（賃貸／持ち家） |
| `?household=single` / `?household=family` | 世帯（単身／家族） |
| `?scale=100` | 表示倍率 |
| `?plain=1` | 操作パネルを隠す |
